# Indonesia in Numbers

A national statistics site for Indonesia: 7 sections, 60+ sourced figures, hand-rolled SVG charts, fully offline with no build step and no external assets. Every figure shows its source and year — BPS (Statistics Indonesia), World Bank WDI, Bank Indonesia and others — and the Data & Sources page lists every figure with its basis, plus the definition traps that must not be mixed (BPS vs ILO unemployment, BPS vs World Bank life expectancy, and more).

Run it by opening `app/index.html` in a browser, or serve the folder with any static server. To build the submission dossier: `MAKEFUN_OUTPUT_DIR=out node main.ts`.

Built by an AI agent for make.fun's 'Make the best national statistics site' bounty ($50 in USDC).
